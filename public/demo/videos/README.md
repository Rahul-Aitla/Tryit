# Demo Videos

Add your demo videos here:

## Recommended Format
- **Format**: MP4 (H.264 codec)
- **Resolution**: 1280x720 or 1920x1080
- **File Size**: Keep under 10MB for optimal loading

## Files to Add

1. **demo.mp4** - Main product demo video
   - Duration: 30-60 seconds
   - Shows: Upload → Processing → Results workflow

### How to Use in README
Reference videos as: `/demo/videos/demo.mp4`

**Example Markdown:**
```markdown
[![Tryit Demo](https://img.shields.io/badge/▶%20Watch%20Demo-MP4-red?style=for-the-badge)](/demo/videos/demo.mp4)
```

Or embed directly:
```html
<video width="100%" controls>
  <source src="/demo/videos/demo.mp4" type="video/mp4">
  Your browser does not support the video tag.
</video>
```
