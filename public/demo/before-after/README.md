# Before & After Images

Add your before/after demonstration images here:

## Directory Structure

```
before-after/
├── winter-jacket/
│   ├── before.jpg
│   └── after.jpg
├── summer-dress/
│   ├── before.jpg
│   └── after.jpg
└── formal-wear/
    ├── before.jpg
    └── after.jpg
```

## Recommended Format
- **Format**: JPG or PNG
- **Resolution**: 400x500px minimum (square or portrait for fashion)
- **File Size**: Optimize to ~50-100KB each

## Naming Convention
- `before.jpg` - Original uploaded garment
- `after.jpg` - AI-generated variation

### How to Use in README
Reference images as: `/demo/before-after/winter-jacket/before.jpg`

**Example Markdown:**
```markdown
![Before: Winter Jacket](/demo/before-after/winter-jacket/before.jpg)
![After: Winter Jacket Variations](/demo/before-after/winter-jacket/after.jpg)
```
